M5Stack StickC Plus2 Pin Mapping:

DISPLAY:
- TFT CS:        GPIO 5
- TFT DC:        GPIO 14
- TFT RST:       GPIO 12
- TFT BL:        GPIO 27
- TFT MOSI:      GPIO 15
- TFT CLK:       GPIO 13

AUDIO:
- Mic WS:        GPIO 34 (I2S Word Select)
- Mic CLK:       GPIO 0  (I2S Clock)
- Buzzer:        GPIO 2  (Tone generation - NO audio playback)

BUTTONS:
- Button A:      GPIO 37 (Call/Answer)
- Button B:      GPIO 39 (Hang up)
- Button PWR:    GPIO 35 (Power)

I2C:
- SDA:           GPIO 32 (Grove)
- SCL:           GPIO 33 (Grove)

OTHER:
- Battery ADC:   GPIO 38

================================================================================
DEPLOYMENT INSTRUCTIONS
================================================================================

1. PREREQUISITES:
   - PlatformIO installed
   - M5Stack StickC Plus2 device
   - USB-C cable
   - SIP server or account

2. CONFIGURATION:
   cd sip-client
   cp include/config.example.h include/config.h
   # Edit config.h with your credentials

3. BUILD:
   pio run

4. UPLOAD:
   pio run --target upload

5. MONITOR:
   pio device monitor

6. TEST:
   - Power on device
   - Wait for "Registered" status
   - Press Button A to call
   - Press Button B to hang up

================================================================================
KNOWN LIMITATIONS
================================================================================

1. Single call only (no call waiting)
2. No DTMF tone generation (planned)
3. Basic authentication only (digest auth planned)
4. No NAT traversal (STUN/TURN planned)
5. G.711 codec only (more codecs planned)
6. NO built-in speaker - only buzzer for tones

WORKAROUNDS:
- External speaker REQUIRED for audio playback
- Use local SIP server or port forwarding
- Ensure G.711 codec on SIP server
